# ACIA : AI Continuous Improvement Assistant

Maquette de démonstration réalisée pour le hackathon IAE Paris-Sorbonne × Neocognition (sujet Scalian, novembre 2026), groupe 1.

**Toutes les données sont fictives.** Aucune personne, aucun mail ni aucun document réel.
La connexion est une connexion de démonstration : elle ne protège rien.

Site publié : https://logjic-jcg.github.io/iae-scalian-gp1/

## Structure

| Fichier | Rôle |
|---|---|
| `index.html` | Page de connexion (choix du profil) |
| `app.html` | Application (onglets selon le profil) |
| `assets/css/style.css` | Styles communs aux deux pages |
| `assets/js/app.js` | Données fictives et écrans de l'application |
| `assets/js/auth.js` | Connexion de démonstration, à remplacer par Firebase Authentication |
| `assets/js/etat.js` | Mémoire de la démo le temps de l'onglet, à remplacer par Firestore |
| `assets/js/firebase-config.js` | Configuration Firebase (vide pour l'instant) |
| `assets/img/` | Logos et visuels |
| `livrables/` | Livrables 01 à 04, jeu de données, schémas |

Voir `FIREBASE.md` pour le branchement prévu.
